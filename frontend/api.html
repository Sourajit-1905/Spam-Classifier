API Specifications

Base URL: http://127.0.0.1:5000  |  Replace with your Render URL after deployment

GET /health

Health check endpoint. Confirms the API is running and model artefacts are loaded.

Response 200
{ "status": "SMS Spam Detector API is running" }
GET /

Serves the landing page (landing.html). Entry point for the web application.

Response 200
Content-Type: text/html Body: landing.html
POST /predict

Classifies an SMS message as spam or not spam. Runs the message through the full NLP pipeline — cleaning, TF-IDF vectorisation, ensemble prediction, and confidence scoring.

Request Body (application/json)
{ "message": "WINNER!! You have been selected for a FREE prize. Call NOW!" }
Field Type Required Description
message string Yes The raw SMS text to classify. Must be non-empty.
Response 200 — Success
{ "prediction": 1, "probability": 0.9421, "safety_score": 5.79, "confidence_label": "Extremely likely spam" }
Field Type Description
prediction int 1 = spam, 0 = not spam. Determined by custom precision-tuned threshold.
probability float Raw spam probability from the ensemble model. Range: 0.0 – 1.0
safety_score float (1 − probability) × 100. Higher = safer. Range: 0 – 100%
confidence_label string Human-readable label from the 20-band confidence scale.
Response 400 — Missing key
{"error": "No message provided"}
Response 400 — Empty message
{"error": "Message is empty"}
Response 500 — Server error
{"error": "Internal server error"}
